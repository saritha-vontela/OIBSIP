# Green Fields - Landing Page

## About the Project
Green Fields is a simple, responsive landing page promoting nature and sustainable living.

## Technologies Used
- HTML5
- CSS3

## Features
- Navigation bar with Home, About, and Contact links
- Hero section with a heading and call-to-action button
- About section
- Contact section
- Responsive layout for smaller screens

## How to Run
1. Download or clone the project.
2. Open index.html in a web browser.

## Project Files
- index.html - Website structure
- style.css - Website styling
